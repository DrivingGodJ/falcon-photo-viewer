# Falcon Photo Viewer

从一整天的连拍里，挑出值得留下的瞬间。Falcon 把快速浏览、焦点检查、双图比较和选片交付放在同一个桌面工具里。

![从连拍浏览到 RAW、1:1 焦点检查、评分标记和选片导出的完整流程](docs/images/falcon-workflow.png)

## 先看动作，再看细节

按住方向键浏览连续画面，观察鸟翼、步伐或表情的变化；停下来时，再查看全分辨率细节。单击想检查的位置进入 1:1，判断焦点是否落在需要的地方。

## 比较的是照片，不是文件

同一次拍摄的 RAW 与 JPEG 合成一个选片单位，不必把同一个瞬间判断两遍。打开双图比较后，两侧同步缩放和平移；固定喜欢的一张，再逐张寻找更好的候选。

## 让选中的照片进入后期

用星级、选中和拒绝整理结果，再复制未经重编码的原片，或导出适合分享的 sRGB JPG/PNG。文件夹直接打开，无需先建立图库；快捷键与右键菜单都能完成常用操作。

Falcon 专注看图与选片，曝光、白平衡和完整修图继续交给后期软件。
