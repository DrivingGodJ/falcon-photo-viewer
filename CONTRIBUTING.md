# Contributing to Falcon Photo Viewer

Bug reports and pull requests are welcome at https://github.com/HWu0101/falcon-photo-viewer.
For bugs, include the app version, operating system, file format and reproduction steps.
Diagnostic logging is optional. Remove personal paths and photos from reports unless you intend
to share them. Never upload passwords, access tokens or private camera files by default.

Discuss interface or interaction changes in an issue before investing in implementation; the
maintainer handles product design. Keep fixes focused and add a regression test when appropriate.
Use the build instructions in BUILDING.md and run the relevant tests on supported platforms.

Unless you explicitly state otherwise, contributions intentionally submitted for inclusion are
under Apache-2.0, the project licence. No separate contributor licence agreement is required.
Only submit material you are entitled to contribute, and preserve third-party notices.

This repository contains reviewed release snapshots. Accepted changes may be integrated in the
private development checkout and appear in the next public snapshot. Contributor authorship and
credit are retained; private development history and unrelated personal material are not published.
